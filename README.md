# NOVA Car Radio

Modern synchronized in-vehicle radio for FiveM with support for **NOVA Framework**, **QBCore**, **ESX Legacy**, and standalone servers.

## Features

- Synchronized vehicle audio
- YouTube and direct audio URL support
- SoundCloud support
- Favorites
- History
- Playlists
- Queue system
- Loop, seek, pause and resume
- 3D vehicle audio
- Audio effects
- Per-character saved data
- Automatic framework detection
- QBCore, ESX Legacy support

### Required

- [oxmysql](https://github.com/overextended/oxmysql)
- [olisound](https://github.com/lone17k/olisound)
- OneSync enabled

### Framework

You only need **one** of the following:

- [QBCore](https://github.com/qbcore-framework/qb-core)
- [ESX Legacy](https://github.com/esx-framework/esx_core)
- NOVA Framework
- Standalone mode

The resource automatically detects the active framework.
